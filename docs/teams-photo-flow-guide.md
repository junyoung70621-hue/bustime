# Teams 자동 업로드 — Power Automate 플로우 설정 (수도권 설치완료) · 상세판

수도권 설치완료 체크리스트를 저장하면 앱이 릴레이 메일함(`RELAY_MAIL_TO`)으로 **두 통**의 메일을 보냅니다.
Power Automate **"새 메일이 도착하면(V2)"** 트리거로 받아 Teams(=SharePoint 문서함)에 자동 반영합니다.

> **V2 트리거 기준입니다.** 출력 참조는 `triggerBody()?['Subject']` 형태(PascalCase)이며,
> 첨부 컬렉션은 `triggerBody()?['Attachments']`, 각 첨부 속성은 `Name` / `ContentBytes` / `IsInline` 입니다.
> (V3는 `triggerOutputs()?['body/subject']`, `body/attachments`, `name`/`contentBytes` — 혼동 금지)

| 메일 | 제목(Subject) | 본문 첫 줄 | 첨부 | 할 일 |
|---|---|---|---|---|
| ① 체크리스트 | `대폐차\|{센터}\|{운수사}\|{날짜}\|{new\|update}\|{이전파일}` | `운수사_차량번호_대폐차_날짜 설치완료` | 캡쳐 **JPG 1장** | 센터 폴더 저장(기존) **+ 채널 스레드 게시(추가)** |
| ② 증빙사진 | `대폐차사진\|수도권\|{센터}\|{운수사}\|{차량번호}\|{날짜}` | (요약) | 현장 사진 **N장**(파일명=항목명) | `사진/수도권/센터/운수사/차량번호` 폴더 저장(신규 흐름) |

- 구분자는 파이프(`|`). 운수사·차량번호의 `\ / : * ? " < > |` 는 앱에서 제거되어 옵니다.
- 사진 메일은 **사진이 1장 이상일 때만** 발송됩니다(촬영 0장이면 미발송, 흐름 ②는 실행 안 됨).
- ①의 본문은 **plain text**라 첫 줄(캡션) 추출이 쉽습니다. `본문 미리 보기(Body Preview)` 사용을 권장합니다.

> **이 문서의 모든 수식은 V2 기준** — `triggerBody()?['Subject']`, `triggerBody()?['BodyPreview']`,
> `triggerBody()?['Attachments']`(각 항목 `Name`/`ContentBytes`/`IsInline`).

> 결과적으로 만들/고칠 흐름은 **(A) 증빙사진 흐름 신규 1개**, **(B) 체크리스트 흐름에 스레드 게시 추가**입니다.

## 0. 공통 준비

1. https://make.powerautomate.com 접속 → 우상단 환경이 회사(에이텍모빌리티) 테넌트인지 확인.
2. 커넥터 연결 3개 준비: **Office 365 Outlook**(릴레이 메일함 계정), **SharePoint**, **Microsoft Teams**.
3. 대상 Teams 채널이 어느 **SharePoint 사이트/문서 라이브러리**에 연결됐는지 확인:
   - Teams에서 채널 → **파일** 탭 → 우측 **···** → **SharePoint에서 열기** → 주소창 URL 메모.
   - 사이트 주소 예: `https://atecmobility.sharepoint.com/sites/대폐차` · 라이브러리: 보통 **문서(Documents)**.

## 흐름 A — 증빙사진 폴더 업로드 (신규)

**목표 경로:** `문서/사진/수도권/{센터}/{운수사}/{차량번호}/{항목명}.jpg`
(SharePoint "파일 만들기"는 경로상 없는 폴더를 **자동 생성**합니다.)

### A-1. 새 흐름 만들기
- 좌측 **+ 만들기 → 자동화된 클라우드 흐름**.
- 이름: `대폐차 증빙사진 업로드`.
- 트리거 검색 → **Office 365 Outlook — 새 메일이 도착하면 (V2)** 선택 → 만들기.

### A-2. 트리거 설정 (새 메일이 도착하면 V2)
- **폴더**: `받은 편지함`.
- **고급 옵션 표시** 클릭 후:
  - **첨부 파일 포함**: `예`
  - **첨부 파일이 있는 항목만**: `예`
  - **제목 필터**: `대폐차사진`  ← 이 단어가 포함된 메일만 트리거(불필요 실행 차단)

> 제목 필터는 "포함" 매칭이라 ②번 메일만 잡힙니다. 그래도 A-3에서 한 번 더 조건으로 못박습니다.

### A-3. 조건으로 한 번 더 거르기
- **+ 새 단계 → 컨트롤 → 조건(Condition)**.
- 왼쪽 값: 식(fx)에 입력
  ```
  startsWith(triggerBody()?['Subject'], '대폐차사진')
  ```
- 가운데: `다음과 같음` · 오른쪽: `true`
- **아니요(거짓)** 분기는 비워둠(아무 동작 없음). 이후 단계는 모두 **예(참)** 분기 안에 넣습니다.

### A-4. 제목 분해 (작성/Compose)
- 예(참) 분기 → **+ 동작 추가 → 데이터 작업 → 작성(Compose)**. 이름을 `제목분해`로 변경(··· → 이름 바꾸기).
- 입력(fx):
  ```
  split(triggerBody()?['Subject'], '|')
  ```
- 분해 결과 인덱스:

  | 인덱스 | 의미 | 예 |
  |---|---|---|
  | `[0]` | 대폐차사진 | 대폐차사진 |
  | `[1]` | 지역(고정) | 수도권 |
  | `[2]` | **센터** | 강남 |
  | `[3]` | **운수사** | 대도운수 |
  | `[4]` | **차량번호** | 70-1234 |
  | `[5]` | 설치일 | 2026-06-24 |

  참조 형태: `outputs('제목분해')?[2]` (센터), `outputs('제목분해')?[3]` (운수사), `outputs('제목분해')?[4]` (차량번호).

### A-5. 첨부마다 파일 만들기
- **+ 동작 추가 → 컨트롤 → 각각에 적용(Apply to each)**.
- "이전 단계에서 출력 선택": 식(fx)에
  ```
  triggerBody()?['Attachments']
  ```
- 루프 내부 → **+ 동작 추가 → SharePoint → 파일 만들기(Create file)**:
  - **사이트 주소**: 0번에서 확인한 사이트(예: `…/sites/대폐차`)
  - **폴더 경로**: 식(fx)에
    ```
    concat('/사진/수도권/', outputs('제목분해')?[2], '/', outputs('제목분해')?[3], '/', outputs('제목분해')?[4])
    ```
    (라이브러리 루트가 "문서"이면 위 경로는 문서 라이브러리 기준입니다.)
  - **파일 이름**: 동적 콘텐츠 **이름(Name)** — 첨부 파일명(예: `차량번호.jpg`)
  - **파일 콘텐츠**: 동적 콘텐츠 **콘텐츠(ContentBytes)**

> 인라인 이미지까지 첨부로 잡히는 게 싫으면, "각각에 적용" 안에 조건 `items('각각에_적용')?['IsInline'] = false` 를 추가해 실제 첨부만 저장하세요. (앱은 인라인 이미지를 보내지 않으므로 보통 불필요)

### A-6. 저장 후 테스트
- 우상단 **저장** → **테스트 → 수동 → 실행**.
- 앱에서 수도권 체크리스트를 사진 1~2장과 함께 저장 → 흐름 실행 성공 → SharePoint
  `사진/수도권/{센터}/{운수사}/{차량번호}/` 에 항목명 파일 생성 확인.

## 흐름 B — 체크리스트 캡쳐 + 차량번호 텍스트 스레드 게시

기존 "체크리스트 → 센터 폴더 저장" 흐름은 **그대로 두고**, 채널 대화(스레드)에 글을 올리는 동작을 추가합니다.
(기존 흐름을 열어 동작을 추가하거나, 아래처럼 새 흐름으로 분리해도 됩니다.)

### B-1. 트리거 / 조건
- 트리거: 흐름 A와 동일(**새 메일이 도착하면 V2**, 첨부 포함=예).
  - 제목 필터를 쓴다면 `대폐차` (단, 이러면 `대폐차사진`도 걸리므로 아래 조건으로 제외).
- **조건**(fx, "그리고" 두 줄):
  - `startsWith(triggerBody()?['Subject'], '대폐차')` = `true`
  - `startsWith(triggerBody()?['Subject'], '대폐차사진')` = `false`

### B-2. 캡션(첫 줄) 추출 — 작성/Compose `캡션`
- 예(참) 분기 → **작성(Compose)**, 이름 `캡션`.
- 입력(fx) — 본문 미리 보기의 첫 줄, 앞뒤 공백/캐리지리턴 제거:
  ```
  trim(replace(first(split(triggerBody()?['BodyPreview'], decodeUriComponent('%0A'))), decodeUriComponent('%0D'), ''))
  ```
  결과 예: `대도운수_70-1234_대폐차_2026-06-24 설치완료`

> `BodyPreview`(본문 미리 보기)는 plain text라 첫 줄 추출이 안정적입니다.
> 만약 값이 비면 `triggerBody()?['Body']`로 바꾸되, HTML이면 태그가 섞일 수 있으니 미리 보기 사용을 권장합니다.

### B-3. 채널에 게시
Teams 채널 게시에서 **이미지를 인라인으로 보이게** 하는 방법은 환경에 따라 제약이 있습니다.
아래 **방법 1(권장, 확실)** → 안 되면 **방법 2(인라인 시도)** 순으로 적용하세요.

#### 방법 1 (권장) — 텍스트 게시 + 캡쳐를 채널 파일로 저장 + 링크
1. **SharePoint → 파일 만들기**로 캡쳐 JPG를 채널 폴더에 저장:
   - 사이트 주소: 채널의 SharePoint 사이트
   - 폴더 경로(fx): 센터별 정리 예 — `concat('/설치완료캡쳐/', split(triggerBody()?['Subject'],'|')?[1])`
   - 파일 이름: 동적 콘텐츠 첨부 **이름**(또는 `concat(outputs('캡션'), '.jpg')`)
   - 파일 콘텐츠: 첨부 **콘텐츠**
     - 첨부가 1장이므로 fx로 첫 첨부만 써도 됩니다:
       `first(triggerBody()?['Attachments'])?['ContentBytes']`
   - 이 동작의 출력 **항목에 대한 링크(Link to item)** 를 다음 단계에서 사용.
2. **Microsoft Teams → 채팅이나 채널에 메시지 게시(Post message in a chat or channel)**:
   - 게시 위치: `Channel`
   - 팀 / 채널: 대상 선택
   - 메시지: `@{outputs('캡션')}` 줄바꿈 후 `📎 캡쳐: @{body('파일_만들기')?['{Link}']}` (캡쳐 파일 링크)
   - → 스레드에 **텍스트(운수사_차량번호_대폐차_날짜 설치완료)** + 캡쳐 링크가 게시됩니다. (파일 탭에서도 열람 가능)

#### 방법 2 (인라인 이미지 시도) — 어댑티브 카드
- Teams 어댑티브 카드는 **이미지 URL**을 넣어야 인라인 표시됩니다.
- **주의:** 카드 본문에 base64 data URI를 직접 넣는 방식은 **카드 크기 한도(~28KB)** 때문에 캡쳐(수백 KB)에는 부적합합니다.
  반드시 방법 1처럼 먼저 SharePoint에 저장한 **파일의 URL**을 이미지 url로 사용하세요(같은 테넌트/팀 권한 내에서 렌더링됨).
- **Teams → 채팅이나 채널에 어댑티브 카드 게시** → 메시지(카드 JSON):
  ```json
  {
    "$schema": "http://adaptivecards.io/schemas/adaptive-card.json",
    "type": "AdaptiveCard",
    "version": "1.4",
    "body": [
      { "type": "TextBlock", "text": "@{outputs('캡션')}", "weight": "Bolder", "wrap": true },
      { "type": "Image", "url": "@{body('파일_만들기')?['{Link}']}", "size": "Stretch" }
    ]
  }
  ```
- 카드에서 이미지가 안 보이면(권한/URL 문제) 방법 1의 링크 방식으로 두세요.

## 점검 체크리스트

- [ ] ①② 메일이 릴레이 메일함에 정상 도착(앱 저장 후 수 초~수십 초)
- [ ] 흐름 A: `사진/수도권/{센터}/{운수사}/{차량번호}/` 에 항목명 파일 생성
- [ ] "없음"/미촬영 항목은 첨부에 없어 폴더에도 생성되지 않음
- [ ] 흐름 B: 채널 스레드에 `운수사명_차량번호_대폐차_날짜 설치완료` 텍스트 + 캡쳐(링크/이미지) 게시
- [ ] SMTP env 미설정 시 앱 저장은 정상, 릴레이만 비활성(흐름 미실행)

## 자주 막히는 곳

- **폴더 경로 슬래시**: 경로는 `/`로 시작, 라이브러리 루트("문서") 기준 상대경로. 한글 폴더명 OK.
- **첨부 콘텐츠 필드명(V2)**: 첨부 항목은 `Name`, `ContentBytes`(동적 콘텐츠 "콘텐츠"), `ContentType`, `IsInline`. 파일 콘텐츠에는 ContentBytes를 넣습니다.
- **V2 vs V3 참조**: V2는 `triggerBody()?['Subject']`·`['Attachments']`·`['BodyPreview']`(PascalCase). V3는 `triggerOutputs()?['body/subject']`·`body/attachments`·`body/bodyPreview`(슬래시·소문자). 트리거를 바꾸면 모든 수식의 참조도 같이 바꿔야 합니다.
- **줄바꿈 문자**: 메일 줄바꿈이 `\r\n`일 수 있어 B-2에서 `%0A`로 자른 뒤 `%0D` 제거를 함께 처리했습니다.
- **본문이 HTML로 옴**: `Body` 대신 `BodyPreview`(plain text)를 쓰세요.
- **트리거가 다른 메일에도 반응**: 제목 필터 + A-3/B-1 조건으로 이중 차단.
